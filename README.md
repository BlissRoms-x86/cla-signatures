# BlissLabs CLA signatures

This repository stores GitHub CLA signatures for BlissLabs projects. Do not
protect the `main` branch. The CLA workflow in each project repo writes here.

Canonical documents:

* [Code of Conduct](https://github.com/BlissRoms-x86/website/blob/master/CODE_OF_CONDUCT.md)
* [Contributor License Agreement](https://github.com/BlissRoms-x86/website/blob/master/CLA.md)
* [Contributing](https://github.com/BlissRoms-x86/website/blob/master/CONTRIBUTING.md)

Corporate CLAs are not stored in this JSON file. Send those to contact@blisslabs.org.
